Cambiare elastici e variante a più set insieme

Solo idee, l'app non è cambiata. Oggi, con più set selezionati, puoi solo mettere una nota o cancellare. Qui, con più set selezionati, le scelte (elastici, variante, presa) restano accese: tocchi quello che vuoi cambiare e compare «Update 3 sets», che cambia solo quello su tutti. Peso, reps, lato, note e riposi di ogni set restano com'erano. Esempio: il tuo Muscle Up del 20, tre set segnati col nero che in realtà erano col rosso.

Da decidere

Set con elastici diversi tra loro. All'inizio nessun elastico è acceso se i set selezionati ne hanno di diversi (qui tutti e tre hanno il nero, quindi il nero è acceso). Quello che scegli diventa l'elastico di tutti, al posto del loro. Se non tocchi gli elastici, ognuno tiene il suo.
