Variant groups

One Arm Pull Up as you would set it up: two groups, picked one from each per set. Range: full · first half · 90° hold. Help: none · band · deload. Your sets keep what they were: deloaded → full + deload (with their −25, −17.5…), resistance band → full + band (with their colors), first half → first half + none, 90° hold → 90° hold + none. Numbers like a width in mm stay as Measurements, below the groups.

1Edit exercise
  • “Variants” holds the groups; each group is a card with its options and how many sets.
  • The first group can change what a set records (90° hold: weight · time).
  • “+ Add a group” for anything you want to combine: grip, band, tempo…
